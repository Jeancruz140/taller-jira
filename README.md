# RPG Manager - Misiones y progresión

Este proyecto contiene el trabajo realizado por el equipo Equipo 4 durante el taller práctico de Scrum (Jira).

El módulo trabajado corresponde a las misiones y el progreso del jugador. Su propósito es permitir que un jugador consulte y reciba misiones, complete sus objetivos, obtenga experiencia y avance entre nivel.

## Contenido del proyecto

En este proyecto se encuentran:

- El Product Backlog con ocho historias de usuario.
- La priorización de las historias mediante MoSCoW.
- Las estimaciones realizadas con Planning Poker.
- La planificación del Sprint 1 con una capacidad máxima de 13 puntos.
- Las evidencias del tablero y del avance del Sprint.
- Las decisiones tomadas frente a los incidentes planteados durante el taller.
- La Sprint Review.
- La retrospectiva del equipo.



## Sprint 1

El objetivo del Sprint 1 fue permitir que el jugador recibiera y completara misiones, además de consultar las misiones disponibles.

Las historias seleccionadas fueron:


| Historia  | Descripción                    | Puntos |
| --------- | ------------------------------ | ------ |
| US02      | Recibir una misión             | 5      |
| US04      | Completar una misión           | 5      |
| US01      | Consultar misiones disponibles | 3      |
| **Total** |                                | **13** |


Las demás historias quedaron disponibles para futuros Sprints debido al límite de capacidad establecido para cada ejercicio.

## Retrospectiva

La retrospectiva reúne los aspectos que el equipo comenzará a hacer, dejará de hacer y mantendrá en próximas sesiones. También registra el compromiso del equipo para mejorar la comunicación, la autonomía y el seguimiento de las actividades.

El detalle se encuentra en el archivo `[retrospectiva.md](retrospectiva.md)`.
